NutriTrack - Indian Calorie Tracker
A comprehensive calorie and nutrition tracking web application specifically designed for Indian cuisine, featuring a modern dark/light mode interface and detailed nutritional analysis.
Brief Description
NutriTrack is a feature-rich calorie tracking application that helps users monitor their daily food intake with a focus on Indian foods. The app includes a comprehensive database of common Indian dishes, personalized health metrics calculation, and visual progress tracking. Users can log their meals, track macronutrients, set daily calorie goals, and monitor their progress over time with an intuitive, responsive interface.
Key Features

Indian Food Database: Pre-loaded with 20+ common Indian foods including dal, roti, biryani, paneer dishes, and regional specialties
Smart Health Calculations: BMI calculator and maintenance calorie estimation using Harris-Benedict formula
Daily Tracking: Log meals with customizable serving sizes and real-time nutrition summaries
Progress Visualization: 7-day calorie intake chart with goal tracking
Personalization: Adjustable daily goals, activity levels, and personal health metrics
Dark/Light Theme: Modern UI with seamless theme switching
Date Navigation: Track food intake for any past date
Nutritional Breakdown: Detailed macronutrient analysis with percentage breakdowns
Quick Add: Fast-access buttons for commonly consumed foods
Responsive Design: Mobile-friendly interface that works across all devices
